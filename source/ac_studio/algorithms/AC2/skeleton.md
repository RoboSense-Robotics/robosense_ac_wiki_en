# 3D Human Skeleton Keypoint Detection

This example provides a project that performs 3D human skeleton keypoint detection by fusing LiDAR and image information. Using the images and point cloud data from AC2 as input, the system can detect the 3D coordinates of human skeleton keypoints in real time within the 3D space.
