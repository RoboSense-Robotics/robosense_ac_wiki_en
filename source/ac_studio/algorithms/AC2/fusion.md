# Point Cloud Vision Fusion

This example demonstrates how to fuse point clouds with stereo RGB images to generate point clouds with RGB color information in real time.

In the following video, the left image shows the raw image from the left camera of AC2, while the right image shows the point cloud with RGB color information after fusion.
