# Small Object Detection

This example uses screws as a case study to demonstrate the performance of AC2 in small-object segmentation tasks.

The video not only shows the segmentation results on 2D images, but also combines the high-precision depth estimation point cloud generated by robosense_ac_depth that mentioned in the previous section. Based on the 2D segmentation results, it is further possible to obtain 3D segmentation results.
