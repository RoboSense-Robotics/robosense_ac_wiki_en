# Dense Depth Estimation

This example provides a C++ inference framework demonstrating how to apply the current state-of-the-art (SOTA) depth estimation algorithm, FoundationStereo, to the stereo images from AC2, in order to generate high-quality dense depth results.

The video below shows the depth estimation inference results using AC2 data.
The left image shows the raw image from AC2, the middle image shows the disparity map, and the right image shows the 3D point cloud computed from the disparity map and the stereo camera parameters of AC2.
